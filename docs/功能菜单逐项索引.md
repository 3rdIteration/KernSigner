## QR Sign

Common paths:

```text
Home -> QR Sign
├─ OKX
│  ├─ Mnemonic
│  └─ Smart Card
├─ Bitget
│  ├─ Mnemonic
│  └─ Smart Card
├─ MetaMask
│  ├─ Mnemonic
│  └─ Smart Card
├─ Rabby
│  ├─ Mnemonic
│  └─ Smart Card
├─ TokenPocket
│  ├─ Mnemonic
│  └─ Smart Card
└─ BTC
   ├─ Mnemonic
   └─ Smart Card
```

Supported purposes:

| Scanned Content | Common Result | Notes |
| --- | --- | --- |
| BTC PSBT | Verify transaction then sign, display signed result QR code | Prioritize local mnemonic main line |
| Web3 Request | Choose Mnemonic or Smart Card source, verify then sign | Cancel if you don't understand contracts/authorizations |
| Multi-page UR/BBQR | Continue scanning completely as prompted | Missing fragments will fail |
| Message Signature Request | Verify message then sign | Do NOT sign unfamiliar login messages |
| Descriptor/Address/Public Key | Parse or assist import | Not equivalent to signing |
| Mnemonic QR Code | May enter import or parse flow | QR codes = private key materials |

Supported format quick reference:

| Category | Supported Content | Purpose |
| --- | --- | --- |
| Standard Single-frame QR | Text, addresses, descriptors, base64 PSBT, message signature requests, mnemonics | Basic scanning and parsing |
| `pNofM` Dynamic/Fragmented QR | Multi-frame text like `p1of3` | Auto-collect then concatenate |
| UR | `ur:*` single or multi-frame | Handle PSBTs, descriptors, bytes, Web3 requests etc. |
| UR PSBT | `ur:crypto-psbt/...` | Parse PSBT then sign |
| UR Descriptor | `ur:crypto-output/...`, `ur:crypto-account/...` | Extract or verify wallet descriptors |
| UR Web3 | `ur:eth-sign-request/...` | Web3 signing requests |
| BBQR | `B$...` | Often used for high-density PSBTs or transaction data |
| TokenPocket Multi-fragment | `tp:multiFragment-...` | Collect and verify multi-fragment requests |
| SeedQR | 4-digit index | Mnemonic import/backup |
| Compact SeedQR | 16 or 32 byte binary entropy | 12/24 word mnemonic import/backup |
| Plain Mnemonic QR | Space-separated BIP39 English words | Temporary import or recovery drills |

QR code format being recognized does NOT mean the content is safe. Before signing, you MUST still verify amounts, addresses, change, fees, chains, contracts, and authorizations on KernSigner.

If QR codes are too dense, first confirm the ESP32-P4 4.3 OV5647 camera has been focused with a standard QR code, then screenshot or cast to computer to enlarge; for QR and OKX dot dynamic code troubleshooting, see [QR_CAMERA_TROUBLESHOOTING.md](QR_CAMERA_TROUBLESHOOTING.zh-CN.md).

### Web3 Wallets

Each Web3 wallet has two sources:

```text
Home -> Connect Wallet -> OKX -> Mnemonic
Home -> Connect Wallet -> OKX -> Smart Card
```

`OKX` can be replaced with:

```text
Bitget / MetaMask / Rabby / TokenPocket
```

| Source | Meaning | Which PIN to Enter |
| --- | --- | --- |
| `Mnemonic` | Uses the local mnemonic currently loaded in KernSigner memory | Device PIN |
| `Smart Card` | Uses Satochip signing account capability plugged into card reader; SeedKeeper primarily stores secrets, signs as `Mnemonic` source after importing to local | Smart Card PIN |

In phone wallets, select `Hardware Wallet`, `Keystone`, or `QR-based`. Do NOT import mnemonics or private keys.

### Derived Address

```text
Home -> Connect Wallet -> Derived Address
```

Purpose:

- View addresses for specified paths.
- Verify whether phone wallet addresses match KernSigner.
- Troubleshoot network, address type, account number, and passphrase differences.

### Write Card

```text
Home -> Mnemonic -> Write Card
├─ SeedKeeper
└─ Satochip
```

Before writing to card, confirm:

- Current mnemonic is the one to be written.
- Paper backup has been made.
- Smart card PIN/PUK have been recorded.
- Card reader is connected to powered OTG/Hub.

### Passphrase

```text
Home -> Mnemonic -> Passphrase
```

Used to set BIP39 passphrase. It changes wallet fingerprint and all addresses.

## Current Capability Boundaries

| Capability | Current Stance |
| --- | --- |
| BTC mnemonic watch and PSBT flow | Test fund acceptance main line |
| Web3 OKX/Bitget connection and test signing | Connected to test main line |
| MetaMask/Rabby/TokenPocket | Entries available, still need more sample regression |
| Satochip Web3 connection/signing | Test card acceptance scope |

| Secure Boot production lock | Documentation is roadmap/gate, not currently completed proof |

## Terminology Unification

| How It's Written in Docs | Meaning |
| --- | --- |
| Device PIN | KernSigner device's own PIN |
| Smart Card PIN | Satochip/SeedKeeper card's own PIN |
| PUK | Smart card PIN rescue code |
| Mnemonic | BIP39 words; leak = private key leak |
| Passphrase | BIP39 passphrase; changes wallet |
| Watch Wallet | Only views addresses and constructs transactions, does NOT store private keys |
| Connection QR Code | KernSigner shows for wallets to scan, used to add hardware/watch accounts |
| Signature Request QR Code | Phone wallet shows for KernSigner to scan, used to request signing |
| Signature Result QR Code | KernSigner shows for phone wallet to scan, used to transmit signatures back |
