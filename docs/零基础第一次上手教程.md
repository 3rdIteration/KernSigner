# Zero to First-Time Setup Tutorial

Date: 2026-05-21

This tutorial is for anyone encountering KernSigner for the first time. You do NOT need to understand hardware wallets, BIP39, PSBT, or smart cards beforehand; just follow the steps and you'll complete a safe test flow.

**KernSigner is currently still in test fund acceptance mode.** Do not import real mnemonic phrases or store real assets until you have completed the commercial release gate, device acceptance testing, and independent security audit.

## Know These Four Roles First

| Name | What It Does | What It Does NOT Do |
| --- | --- | --- |
| KernSigner development board | Offline creation/import of mnemonics, display addresses, QR code signing | Does not connect to network or broadcast transactions |
| Phone or computer wallet | Create watch-only wallets, initiate transactions, broadcast transactions | Should NOT store KernSigner's mnemonic phrases |
| Computer to enlarge QR codes | Enlarge dense or small Web3 QR codes for the board to scan | Does not store mnemonics or sign on your behalf |
| BIP39 tool | Offline verification that mnemonics and raw entropy match | Do NOT enter real mnemonics on internet-connected websites |

## Step 0: Preparation

You need:

- KernSigner development board and USB data cable.
- Camera module; first use requires manual focus adjustment with a standard QR code.
- Paper and pen.
- A phone or computer.
- Test-only wallets or testnet assets.
- Optional: smart card and powered card reader.

First, unlearn habits like taking photos with your phone, auto cloud sync, and clipboard auto-upload. Once mnemonics are photographed or uploaded, they are considered leaked.

## Step 1: Power On and Set PIN

1. Plug USB to power KernSigner.
2. Wait for the screen to light up.
3. If prompted to set PIN, set a device PIN you can remember but others cannot guess.
4. If prompted to enter PIN, enter your device PIN.
5. Once on the home page, do NOT connect real wallets yet.

Notes:

- `Enter PIN` refers to the device PIN.
- `Smart Card PIN` refers to the card's own PIN.
- They are NOT the same thing.
- ESP32-P4 4.3 camera is NOT phone auto-focus. On first use, open the camera or QR scanner page first; hold a standard QR code at 10-20 cm and gently rotate the OV5647 lens outer ring until it appears clearest.

For PIN details, see [SECURITY_PIN_GUIDE.md](SECURITY_PIN_GUIDE.zh-CN.md).

## Step 2: Create a Test Mnemonic Phrase

For your first practice, we recommend creating a test mnemonic phrase, NOT importing a real wallet.

Path:

```text
Home -> Mnemonic -> Create
```

Recommended methods for beginners:

| Method | Why Recommended |
| --- | --- |
| `Hex` | Easiest to verify character-by-character with BIP39 tools |
| `Camera` | Closest to daily use; suitable for testing camera and random entropy flow |

If just verifying the flow, you can use 128-bit hex entropy with all zeros:

```text
00000000000000000000000000000000
```

This produces a PUBLIC test mnemonic that can only be used for practice, NOT for real funds.

For more creation methods and verification approaches, see [MNEMONIC_CREATION_BIP39_VERIFY.md](MNEMONIC_CREATION_BIP39_VERIFY.zh-CN.md).

## Step 3: Verify with BIP39 Tool

The goal of verification is to confirm: KernSigner generates the same mnemonic from the same raw entropy as the BIP39 tool.

Beginners follow this:

1. Download and open a BIP39 tool offline.
2. Set language to `English`.
3. Check `Show entropy details`.
4. On KernSigner, open the `Raw Entropy` page for your current mnemonic.
5. Fill the hex raw entropy shown on KernSigner into the BIP39 tool's `Entropy` field.
6. Set `Mnemonic Length` to `Use Raw Entropy`.
7. Compare whether the generated English mnemonic matches exactly.

Do NOT enter real mnemonics into internet-connected websites. For detailed screenshot-style flow, see [MNEMONIC_CREATION_BIP39_VERIFY.md](MNEMONIC_CREATION_BIP39_VERIFY.zh-CN.md).

## Step 4: Backup First, Then Continue

After creating a mnemonic, the first thing to do is NOT receive funds; it's backup and recovery drills.

Simplest backup:

1. Go to your current mnemonic's backup page.
2. Select plain text mnemonic.
3. Write down each word and its index in order on paper.
4. After writing, read back and verify.
5. Clear the current session, then re-import once.
6. Verify wallet fingerprint and first address match.

Do NOT only backup QR codes. Do NOT photograph mnemonics. Do NOT upload to cloud storage.

For complete backup details, see [BACKUP_AND_RECOVERY_GUIDE.md](BACKUP_AND_RECOVERY_GUIDE.zh-CN.md).

## Step 5: Connect a Watch-Only Wallet

A watch-only wallet can only view addresses and construct unsigned transactions; it does not store private keys.

Common routes:

| Scenario | How-To |
| --- | --- |
| BTC | KernSigner displays xpub/ypub/zpub, phone or computer wallet imports watch account |
| Web3 | KernSigner generates connection QR code, OKX/Bitget/MetaMask/Rabby/TokenPocket scans to add hardware account |
| QR too dense | First confirm camera is focused, then screenshot or cast to computer to enlarge for the board to scan directly |

You MUST verify addresses on KernSigner before receiving funds. If the address shown on your phone does NOT match KernSigner, STOP operations.

For connection flows, see [连接钱包教程.md](连接钱包教程.zh-CN.md).

## Step 6: Perform a Test Signature

BTC test:

1. Watch-only wallet creates a small test transaction.
2. Wallet displays PSBT QR code.
3. KernSigner scans the QR code.
4. On KernSigner, verify recipient address, amount, change, and fees.
5. Enter device PIN.
6. KernSigner displays signed result QR code.
7. Wallet scans back and broadcasts the test transaction.

Web3 test:

1. Phone wallet initiates a test transaction using your KernSigner account.
2. If QR codes are too dense, first confirm camera is focused, then screenshot or cast to computer to enlarge for KernSigner to scan directly.
3. KernSigner scans the request QR code.
4. Verify chain, address, amount, contract, and authorization.
5. Choose local mnemonic or smart card signing.
6. Phone wallet scans back the result.

If you cannot understand transaction content, do NOT sign.

## Step 7: Safe Exit After Use

1. Return to Home.
2. Clear current session or power off.
3. Unplug USB.
4. Store paper backups securely.
5. Confirm your phone did not save mnemonic phrase photos.
